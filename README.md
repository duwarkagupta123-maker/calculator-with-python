# 🧮 Scientific Calculator Web App

An interactive **Scientific Calculator** built using Python and Streamlit.
This app supports both basic arithmetic operations and advanced mathematical functions with a clean and user-friendly interface.

🚀 **Live Demo:**
👉 https://calculatorviapython.streamlit.app

---

## ✨ Features

### 🔢 Basic Operations

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division

### 🔬 Scientific Functions

* √ Square Root
* xʸ Power
* log / ln (Logarithmic functions)
* sin, cos, tan (Trigonometric functions)
* Factorial (if implemented)
* Constants like π and e

## ▶️ Run Locally

1. Clone the repository:

```bash id="k92k2a"
git clone https://github.com/duwarkagupta123-maker/calculator-with-python.git
```

2. Navigate to the project folder:

```bash id="3k5t9c"
cd calculator-with-python
```

3. Install dependencies:

```bash id="w2k4lo"
pip install -r requirements.txt
```

4. Run the app:

```bash id="j9sd82"
streamlit run app.py
```
